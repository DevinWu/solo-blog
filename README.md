## 🌟 Key Features

- **Modern Glassmorphic UI**: High-aesthetic responsive web app supporting both **Dark** and **Light** color themes.
- **Fast Client-Side SPA**: Instant keyword search, tag filtering, reading time estimation, and deep-link article sharing (`#post-slug`).
- **Syntax Highlighting & Markdown Engine**: Rich markdown rendering with code block syntax highlighting powered by `Marked.js` and `Highlight.js`.
- **Zero-Build Deployment**: Standard HTML5/Vanilla CSS3/JavaScript structure natively hosted on **GitHub Pages**.

## 🚀 Local Development & Preview

To preview the blog locally:

```bash
# Clone the repository
git clone https://github.com/DevinWu/solo-blog.git
cd solo-blog

# Launch local HTTP server
python3 -m http.server 8080
```

Open your browser at `http://localhost:8080` to view the live blog.
